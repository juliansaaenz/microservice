# libros-service

Microservicio dueño del catálogo de libros. Spring Boot 3 + Thymeleaf + H2. Puerto **8081**.

- Vistas: http://localhost:8081/libros
- API: http://localhost:8081/api/libros
- Lo consume: [prestamos-service](../prestamos-service) por HTTP.

Ejecutar: abrir en NetBeans > Run (o `mvn spring-boot:run`).
